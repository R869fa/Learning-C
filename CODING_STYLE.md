# C Coding Style

 This document describes the coding conventions currently used in this project.

 The main purpose of these conventions is to keep the code readable and consistent while I learn the C programming language.

## Language

 Use English throughout the code.
 Use English for comments and user-facing messages.

## Comments

 Write comments in English.
 Comments can be more detailed when they are being used for personal study or to document something I want to memorize or study.

## Formatting

I opted to place opening braces on a new line:

 if content 
 {
    //content
 }
 
 instead

 if content {
    //content
 }
